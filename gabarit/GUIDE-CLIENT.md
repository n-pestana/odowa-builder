# ✨ Odowa Builder · votre site, en une conversation

Vous modifiez votre site en écrivant à Claude, en français courant. Rien à installer, rien de technique.

## Deux sites, zéro risque

| | Qui le voit | Quand il change |
|---|---|---|
| 🧪 **Site de test** | Vous seul | À chaque modification, pour regarder tranquillement |
| 🌐 **Site en ligne** | Vos visiteurs | Uniquement quand **vous** tapez `/publier` |

## En quatre gestes

1. **💬 Demandez.** « Change les horaires du samedi », « ajoute une page sur nos tarifs », « remplace la photo de l'accueil par celle-ci ».
2. **👀 Regardez.** Claude vous donne le lien du site de test. Ouvrez-le sur votre ordinateur **et** sur votre téléphone.
3. **✏️ Ajustez** autant que vous voulez : « le titre est trop long », « remets l'ancienne photo ».
4. **🚀 Publiez** en tapant `/publier`. Claude vérifie tout, vous montre ce qui part et vous demande de confirmer.

## Les couleurs

À la fin de chaque réponse, Claude vous montre où en sont vos deux sites :

| | Signifie |
|---|---|
| 🟢 | Vérifié, tout va bien |
| 🟡 | C'est à vous : quelque chose attend que vous regardiez ou publiiez |
| ⏳ | En cours, un instant |
| 🔴 | Quelque chose bloque : Claude vous explique quoi |
| ⚪ | Pas pu vérifier pour le moment |

Une couleur n'est verte que si elle a vraiment été vérifiée.

## Les commandes

| Vous tapez | Ce qui se passe |
|---|---|
| `/aide` | Tout ce que vous pouvez faire. |
| `/etat` | Où vous en êtes. |
| `/voir` | Vos modifications partent sur le site de test. |
| `/verifier` | Claude contrôle le site et vous fait un rapport. |
| `/publier` | 🌐 Le site de test devient le site en ligne. |
| `/annuler-publication` | 🌐 La dernière publication est annulée. |
| `/recommencer` | Le site de test repart de l'état du site en ligne. |
| `/prevenir-nicolas` | Nicolas est prévenu, avec le détail de la situation. |

Tapez les commandes en entier : elles n'apparaissent pas dans le menu de l'application. Les deux commandes marquées 🌐 ne se lancent que si vous les tapez vous-même.

## Bon à savoir

- **Vous ne pouvez rien casser en ligne par accident.** Si un contrôle détecte un problème (lien cassé, page sans titre, formulaire en panne), la publication est refusée et Claude vous explique pourquoi.
- **Le site en ligne ne vous plaît pas** juste après une publication ? Tapez `/annuler-publication` : il revient à sa version précédente en quelques minutes.
- **Vous êtes bloqué** ? Tapez `/prevenir-nicolas`. Pas besoin d'expliquer la technique, Claude s'en charge.
- Certaines modifications (le fonctionnement du formulaire, la structure technique du site) sont réservées à Nicolas. Claude vous le dira et le préviendra.
